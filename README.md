\# AI-Based Ovarian Tumor Segmentation from Ultrasound Images



A deep-learning research prototype for segmenting ovarian tumor regions in ultrasound images using a U-Net convolutional neural network.



> \*\*Important:\*\* This project is intended for educational and research purposes. It is \*\*not a medical diagnostic tool\*\* and does not determine whether a tumor is benign or malignant.



\## Project Overview



Ovarian ultrasound images can contain regions corresponding to tumors. Manually identifying and outlining these regions can be time-consuming.



This project uses a \*\*U-Net segmentation model\*\* to learn pixel-level tumor regions from annotated ovarian ultrasound images.

\## Dataset



This project uses the \*\*MMOTU (Multi-Modality Ovarian Tumor Ultrasound) dataset\*\*.



The dataset used in this project contains:



\- 1,469 2D ovarian ultrasound images

\- Corresponding pixel-level segmentation masks

\- 1,175 images for training

\- 294 images for validation



The dataset is \*\*not included in this repository\*\*. It must be obtained separately and placed in the expected directory structure.



Expected structure:



```text

data/

├── MMOTU/

│   └── MMOTU/

│       ├── images/

│       │   ├── 1.JPG

│       │   ├── 2.JPG

│       │   └── ...

│       └── labels/

│           ├── 1.PNG

│           ├── 2.PNG

│           └── ...

├── train.txt

└── val.txt

```



\## Model



The project uses a \*\*U-Net\*\* architecture for semantic segmentation.



The model takes an RGB ultrasound image as input and produces a pixel-level prediction mask indicating the learned tumor region.



Main components:



\- Convolutional encoder

\- Bottleneck

\- Transposed-convolution decoder

\- Skip connections

\- Binary segmentation output

\## Training



The U-Net model was trained using:



\- Image size: 256 × 256

\- Batch size: 4

\- Epochs: 10

\- Optimizer: Adam

\- Learning rate: 0.001

\- Loss function: Binary Cross Entropy with Logits



The trained model is saved locally as:



```text

models/unet\_mmotu.pth

```



The model weights are excluded from this Git repository through `.gitignore`.



\## Evaluation



Evaluation was performed on 294 validation images.



Observed results:



| Metric | Score |

|---|---:|

| Average Dice | 0.6716 |

| Average IoU | 0.5529 |



These results are experimental results from this project and should \*\*not\*\* be interpreted as clinical performance.

\## Streamlit Application



The project includes a simple Streamlit interface for testing the trained segmentation model.



Start the application with:



```powershell

streamlit run app.py

```



Then open the local Streamlit address shown in the terminal, usually:



```text

http://localhost:8501

```



You can upload an ultrasound image and view the model's predicted segmentation.

\## Limitations



This project has several important limitations:



\- It performs \*\*tumor-region segmentation\*\*, not cancer diagnosis.

\- The segmentation masks do not by themselves establish whether a tumor is benign or malignant.

\- The model has been trained and evaluated as a research prototype.

\- The dataset and model performance may not represent real-world clinical performance.

\- The system should not be used to make medical decisions.

\- Further validation, testing, and clinical expertise would be required for any real-world medical application.
